# Production direction

Describe the video you want in normal language. This file is intentionally flexible.

Include what matters for this job, for example:

- audience and purpose;
- teaching/content goals;
- tone and pacing;
- visual style and references;
- brand constraints;
- language/RTL requirements;
- must-show examples or diagrams;
- asset preferences or licensing constraints;
- things to avoid;
- any special QA requirements.

Do not repeat repository-wide factory rules here. Those belong in `AGENTS.md` and `docs/PRODUCTION_PLAYBOOK.md`.
